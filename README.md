# Groot Clothing — E-Commerce Platform

**Live site:** [groot-clothing.onrender.com](https://groot-clothing.onrender.com)

A full-stack e-commerce platform built for **Groot Clothing**, a South African streetwear brand based in Marble Hall, Limpopo.

---

## About the Client

**Groot Clothing** was founded by **Malokase** in Marble Hall. The brand designs bold African streetwear and hosts **Groot Annually** — a youth talent showcase held at Moutse West (Zama Gakekana & Ga-Feni).

## Features

### Customer-Facing
- 🛍️ Product catalog with categories and search
- 🖼️ Multi-image product galleries
- 💬 WhatsApp-based ordering system
- 🎉 Event listings (Groot Annually showcase)
- 📞 Contact form with admin notification
- 👤 Customer registration with admin approval
- 🤖 AI assistant ("Groot AI") on homepage for customer questions
- 📱 Fully responsive mobile design

### Admin Panel
- 📊 Dashboard with business stats
- 👕 Product management (create, edit, delete, multi-image upload)
- 👥 User management (approve, ban, delete)
- 🎉 Event management with photo uploads
- 💬 Customer message inbox
- ⚙️ Profile and password management

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | Java EE (Servlets, JSP, JPA/JPQL) |
| **ORM** | EclipseLink 2.7.10 |
| **Database** | MySQL 8.0 (Aiven Cloud) |
| **Server** | Apache Tomcat 10.1 |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Deployment** | Docker → Render |
| **Monitoring** | UptimeRobot (24/7 uptime) |
| **IDE** | NetBeans 17 |
